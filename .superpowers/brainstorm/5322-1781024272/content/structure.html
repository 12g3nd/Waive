How should the site be structured?

This is the most foundational choice — everything else flows from it.

A

Immersive Single Page (polished scroll experience)

Keep the current one-page structure but add richly designed sections: a dramatic hero with animated stats, a "How it works" scroll sequence, the tool itself, and a footer. A judge scrolls and discovers — no navigation needed. Like a premium product launch page.

Pros

  • Tells the full story before the tool appears
  • Maximum visual impact on first impression
  • No routing complexity

Cons

  • Long scroll; tool is "below the fold"
B

Marketing Page + Tool (two distinct experiences)

The landing page is a pure marketing/storytelling experience (hero, problem, how-it-works, sample cases). A clear "Try it now" CTA takes the judge to a dedicated /app page with the tool. Two very different but equally polished pages.

Pros

  • Each page can be fully optimized for its purpose
  • Landing page can be stunning without clutter
  • Judges see the pitch before the tool

Cons

  • Extra navigation hop before the tool
C

Polish-only — Upgrade what's there

No structural changes. The tool is still front-and-center on load. Improvements are entirely about visual richness: better typography, animations, micro-interactions, a richer results page. Fastest to build; lowest risk to the working app.

Pros

  • Fastest; no routing changes
  • Zero risk to the working pipeline

Cons

  • First impression is still "just a tool" with no story
